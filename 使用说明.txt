SoundBin 1.8.5 · Windows 使用说明
==============================

【1.8.5 修了什么】
1) AI 工具里点「管理…」打开的设置不再被 AI 面板盖住（设置抽屉层级提到最上面）
2) 生成完的音频可以就地拖进 DAW：生成板块下面会出现这一批的结果列表，
   点一下 = 试听 + 修剪，按住直接拖 = 进 DAW，不用再回资料库找
3) 第一次按播放的那一下卡顿：程序会在你第一次点界面时提前把音频输出打开，
   把这次初始化挪到点击那一下，之后播放不再顿
4) 生成效果有个真实原因：类型选成「点状动效」时，提示词里会被追加
   single one-shot / dry / close，于是「安静的夜晚街道」会生成一下子很响的声音。
   现在描述里出现 夜晚 / 街道 / 环境 / 公园 这类场景词、类型却是点状动效时，
   面板会直接提示你改类型；同时描述里出现 sparse / occasional / 稀少 / 偶尔 时，
   会自动补 "sparse, low level, distant, near silence between events"

【关于生成质量（实话）】
Stable Audio 这类模型擅长「一片持续的氛围」（雨、风、机器房、海浪），不擅长
「稀疏事件 + 大段安静」（远处偶尔一辆车、夜深人静只有虫鸣）。实测同一句话
（quiet suburban street at night, sparse distant traffic）生成的音频是：RMS −18 dBFS、
每 0.5 秒都高于 −30 dBFS、块间起伏只有 2.3 dB —— 也就是一条不间断的厚噪声；
而库里真实的同类素材是 RMS −27 dBFS、97% 能量在 200 Hz 以下、块间起伏 5.6 dB。
所以「夜晚马路」这类需要真正稀疏、远处、低频滚动的场景，建议先用库里现成素材
（NP02 系列城市夜景/车流），生成留给它擅长的连续氛围。

【关于内容审核】
Stability 会在生成前审核提示词。如果描述里出现「猛砸 / 爆炸 / 尖叫 / 撞击」这类词，
可能直接返回 403 被拦下（本次不计费，余额不会掉）。现在会给出中文提示，
把说法改中性一点即可，例如「猛地关上」→「轻轻关上」。

  · 切到「生成」板块、换配置、每次生成完都会自动重查一次；也可以点「查余额」手动刷
  · 只有 Stability 有余额接口（约 1.57 credits/秒）；ElevenLabs 和自定义服务显示「余额 —」

SoundBin 1.7.6
==============

【1.7.6 新增：启动更快 + 云端音频生成】
1) 启动提速。之前「窗口出来了、但半天点不动、很久才贴上边」的原因是：启动时把整个库
   （8 万多条）一次性丢给主进程核对该文件还在不在，主进程同时发起了 8 万个磁盘查询，
   把读盘队列占满，别的操作全排在后面。现在：
   - 贴边几何在读到偏好后立刻生效（约 0.2 秒内），不再等清单建完；
   - 「文件还在不在」的核对改成后台分块（每块 1200 条、块间让出主线程），不再挡启动；
   - 拔掉的移动盘整卷跳过，不再逐个查。
   实测（8.7 万条库）：窗口出现约 0.7 秒、贴边生效约 2.2 秒、可交互约 2.7 秒；
   后台核对会在十几秒内悄悄跑完，期间可以正常滚动、试听、拖出。

2) 云端音频生成（设置 → AI 与插件 → 音频生成（AI））
   - 支持三家：Stability（Stable Audio 2）、ElevenLabs（音效）、自定义（POST JSON）。
   - 密钥只存在本机（系统加密），界面只看得到「尾号」；可以存多套命名配置随时切换。
   - 用法：在「合成」板块写一句需求 → 点「云端生成」→ 结果自动入库，可试听/修剪/拖进 DAW。
   - 「查余额」：Stable Audio 按秒计费，实测 12 秒立体声约 18.8 credits（≈1.57 credits/秒），
     60 秒一条约 94 credits。生成前先查余额，别一次点太多。
   - 只适合「持续型、没有事件」的声音（风/雨/火/水/机械/人群）。关门、脚步、玻璃碎这类
     短事件不适合生成模型，还是要实录或用素材。
   - 网络失败、密钥不对、额度用完都会在状态行写清楚原因，不会静默降级。

3) 界面收敛（承接 1.7.5）：顶栏只剩「导入 ▾ / 检查器 ▾ / 设置」，信息、相似波形、
   效果器、采样器、VST3、混音、AI 工作台都收进「检查器 ▾」；AI 工作台三个板块改名为
   「检索 / 合成 / 混音」。

SoundBin 1.7.0 · Windows 使用说明
==============================

【1.7.0 这次改了什么】（生成底噪 → 改名「造声」，并修了一批真问题）
- 名字与入口：原来藏在「效果 ▾」里、叫「生成底噪」，现在改叫「造声 · 合成环境底噪」，
  入口在「AI 检索」面板的按钮行（检索 / 只看结果 / 显示全部 / 造声…）；效果菜单里那个入口保留。
- 时段不再错配：候选素材会标 [白天] / [夜] / [晨昏]，要「夜晚的公园」时白天才有的鸟叫会被直接剔掉
  （候选池够大才剔，太小就只往后排，不会因为库小就造不出来）。
- 时长可自定义：5–600 秒随便填，不再只有 60/90/120 三档。
- 一次出多条：条数可选 1–4，每条是同一套素材的变体（层内素材顺序、层电平、纹理种子都会变），
  自己听一遍挑一条，不用反复点「生成」。
- 结果可直接拖进 DAW：每条生成完就落成临时 wav（在 generated\_preview\ 里，只保留最近 60 个），
  列表里那一行按住就能拖到 Pro Tools / Reaper / Cubase；拖出去的就是听到的那一版。
- 「详细」面板：点候选行上的「详细」，能看到这条是由哪几层、哪几条素材、各多少 dB 合成的，
  每层都有滑杆（−18…+3 dB），改完点「按这个比例重做」，只重做这一条，不动其它候选。
- 多套 AI 配置：设置 → Agent 语义检索 里多了「配置」下拉与「另存为新配置 / 删除这套」。
  可以存多组「接口 + 模型 + 密钥」，随时切换（切完立刻生效，不用重启）。同名再存一次是改它，不会重复。
- 修掉的坑：推理型模型（deepseek-flash 这类）会把 token 预算烧在思考上，之前分层请求经常空返回、
  悄悄退回本地规则；这次给足预算，状态行也会直接写「模型这次没给可用结果（原因）」。
  另外「缝合」模式下「底色」下拉会灰掉（那一栏只对纹理/混合有意义）。

【怎么用】
1. 解压压缩包，得到 SoundBin 文件夹（里面是 SoundBin.exe）。
2. 放到可写位置（桌面、D 盘都行），双击 SoundBin.exe 就能用，不需要安装。
3. 数据在 SoundBin.exe 旁边的 data 目录里，整个文件夹可以整体拷贝。

- 面板上多了两个下拉框：模式（缝合库素材 / 纹理合成 / 纹理 + 库细节）与底色（棕噪 / 粉噪 / 白噪）。
- 纹理合成：不走素材库，直接合成一条持续型底噪。软件会把你的需求（比如「老式空调的持续嗡嗡声，
  低频要有一点压迫感」）翻译成参数——底色、低切、高切、呼吸快慢、起伏强弱、低频轰鸣，
  然后再合成、首尾对齐、按响度归一。适合风、雨、机房、空调、远处车流这类「没有事件、只有底色」
  的声音：长度随便定，接缝是算出来的，一定可循环。
- 纹理 + 库细节：纹理铺底，再按需求从库里挑一层细节叠上去（比如雨夜老街 = 粉噪雨底 + 郊区夜车流），
  细节层的电平由模型给建议。
- 缝合模式（1.5.0 那套）也升级了：模型现在会给每层建议电平（低频铺底 0 dB、鸟鸣中景 −6 dB、
  细碎高频 −14 dB），并在每层后面写一句「这层负责什么」；同一条素材最多出现在两层里，避免自叠。
- 面板上的层列表会写出：纹理参数（低切/高切/呼吸/起伏/轰鸣 + 一句理由）以及每层的标签、电平、
  用了哪几条素材、为什么这么分。
- 实测（60 秒、-23 LUFS）：纹理合成约 1.7 秒出结果；缝合约 4.8 秒（含两次模型调用）；
  三种模式的循环点都判定为无缝（接缝跳变小于素材自身相邻样点差的 1%）。
- 没配 AI 接口时，纹理参数走关键词规则（风/雨/车流/室内各有一套），状态行会标「本地降级」。
【1.5.0 新增：生成底噪（把库里的素材缝成一条可循环的环境声）】
- 入口：效果器菜单（波形条左下「效果 ▾」）→「生成底噪：缝合 / 循环 / 归一…」。
- 用法：写一句需求（例：夜晚海边安静的底噪，只有海浪和一点点虫鸣）→ 选层数（1–5）/ 时长
  （20–300 秒）/ 目标响度（-23 / -20 / -16 LUFS）→ 点「生成」。软件会先按需求从库里挑素材、
  分好层（低频铺底 / 中频质感 / 高频细节），再解码、交叉淡化拼接、按响度归一。
- 生成完状态行会给：秒数、层数、实测 LUFS、峰值 dBFS、循环点是否无缝。下面列出每层用了哪几条
  素材；不点「保存并入库」不会写盘，面板里的成品只留在内存。
- 「试听」直接听成品；「保存并入库」写到 <数据目录>\generated\BED_需求前几个字_时长.wav，
  并且自动加进清单（用算好的峰值/波形，不用等分析）。
- 循环点：拼接用等功率交叉淡化 + 首尾窗口再叠一次，实测接缝跳变只有素材自身相邻样点差的
  0.3%–2%，可以整段循环用。
- 说明两点：①不填 AI 接口时用本地规则分组（状态行会标「本地降级」），能用但不如模型挑得准；
  ②生成的底噪自己也在库里，但生成时会自动排除 generated 目录里的文件，避免越叠越糊。

【1.4.4 改进】
- 「历史」「已保存」从检索按钮那一排挪到检索框右下角（和「＋ 导入图片」同一行的最右侧），
  检索区那一排只留：检索 / 只看结果 / 显示全部 / 保存。
【1.4.3 改进：检索记录分成两种】
- 「历史」：每次检索（AI 或本地）结束后自动记一条，不用点任何按钮。点一条就回到那次的
  搜索结果，需求词也一起恢复；右侧的 × 可以删单条，右上「清空」清掉全部历史（最多 60 条）。
- 「已保存」：只有点「保存」才会进来，用来收藏几句常用的检索（最多 40 条）。
  历史里也一直有它，两个列表互不影响。
- 旧版本手动保存过的检索，升级后会自动归到「已保存」里，不会丢。

【1.4.2 起已有】
- Agent 语义检索：模型先给出「范围 + 具体关键词」再去全库召回，不再被本地词表局限
  （比如「狗叫」会去动物类素材里找）；「全库扫描」仍然可用作保底。
- 设置分三块：常规 / 数据与位置 / AI 与插件，记住上次看的那块。
- AI 结果列表也能悬停试听（和主列表一样：停 0.3 秒起播、播 8 秒自停、不抢手动播放）。
- 悬停试听的停留时长可在设置里拖动（0.1–3.0 秒），也可以整体关掉。
- 找回丢失素材：插上移动盘后每 30 秒自动复查一次；设置里可手动「重新检查」或「按新位置找回」。
- 数据位置迁移：换盘时点「迁移到…」，整个 data 目录搬走并记住新位置，自动重启。
- 清单备份：每天第一次启动自动备份一份（保留 7 天），也可「立即备份」，点日期可恢复。

【常见问题】
- 拖进 DAW：按住列表里的一行直接拖到 Pro Tools / Reaper 的时间线；开着效果器或划了修剪
  区间时，拖出去的是处理后的版本。
- 显示「文件缺失」：素材被移动或磁盘没挂载。插回盘后会自动复查；盘符变了用「按新位置找回」。
- 响度/频谱：点开右侧信息面板即可看到（LUFS-I、数字峰值、LRA、频谱图），本地计算。
- 批量工作流：右键任意素材 →「批量工作流…」，可复制到工程目录、按 UCS 改名、写回 WAV 标签、
  导出选片单 CSV。
- 杀毒软件拦截：程序未做代码签名，选择"允许运行"即可。
